# Wholesale Customer Clustering – Streamlit App

Interactive version of the lab notebook (hierarchical + divisive clustering).

## Run
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Data
Put `Wholesale customers data.csv` (UCI Wholesale Customers dataset) in this folder,
or upload it from the sidebar when the app starts.

## Files
- `app.py` – Streamlit UI (10 tabs)
- `clustering.py` – clustering logic ported from the notebook
